# tablekit — 气动阀门数据表 PDF → 选型报价表

把供应商/设计院发来的**气动阀门数据表 PDF**，自动解析并填进**选型报价表模板**，
一台阀一行；版式不认识时可以在窗口里核对、批量映射，改完存回配置、下次自动复用。

> 只处理**有文字层**的 PDF（设计院发的数据表都属于这种）。
> 扫描件/纯图片读不出内容，会明确报错——本工具不做 OCR。

---

## 一、安装

### 1. 需要什么

- Windows（bat 是批处理脚本）；Python **3.10+**
- 能读 PDF 文字层（不需要 Office）

### 2. 装依赖（推荐用虚拟环境）

```bat
cd /d <项目目录>
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

`requirements.txt` 里是实测通过的版本：

```
pdfplumber  0.11.10    读 PDF 表格
pymupdf     1.28.2     页面渲染（核对窗口、划线检测）
openpyxl    3.1.5      读写 xlsx
xlrd        1.2.0      读模板 .xls
numpy       1.26.4     语义模块
pillow      12.3.0     核对窗口显示页面
onnxruntime / tokenizers   仅"智能字段对齐"需要
```

不想建 venv 也行，装到系统 Python 里即可；三个 bat 会按
**项目内 `.venv` → `py` → `python`** 的顺序自己找。

### 3. 检查装好了没

```bat
python -c "import pdfplumber, openpyxl, pymupdf, xlrd; print('ok')"
```

### 4. 目录里应该有

```
pdf_table_master.py     入口（菜单/一键模式）
fill_from_extract.py    解析与填表引擎
pdf_review.py           映射核对窗口（单格框选）
map_workbench.py        映射工作台（批量映射）
semantic_map.py         字段名语义对齐（可选）
mappings\               版式配置（一类 PDF 一个 json）
models\bge-small...     语义模型（可选，约 24MB）
气动球阀（蝶阀）选型报价表.xls    模板（不要改名）
启动工具.bat / 批量映射.bat / 完整菜单.bat
```

## 二、运行

三个 bat，按需要选一个：

| bat | 用途 | 怎么用 |
|---|---|---|
| **`启动工具.bat`** | **一键出报价表**（最常用） | 把 PDF **拖到 bat 图标上**；或双击后按回车，从本目录 PDF 列表里选 |
| **`批量映射.bat`** | **新版式/映射不对时**：左右对照 + 批量改映射 | 同样支持拖 PDF；打开"映射工作台"窗口 |
| `完整菜单.bat` | 8 项菜单（含空值体检、版式清单等） | 双击，按数字选 |

出报价表只要第一条。生成的文件是 `<PDF名>_报价表.xlsx`，
一键模式会放在 `<PDF名>\` 同名文件夹里并自动打开。

### 选 PDF 的三种方式（三个 bat 通用）

1. 把 PDF **拖到 bat 图标上**（不是拖进已打开的窗口，Windows 控制台不接收拖放）；
2. 双击 bat 后**直接按回车** → 列出本目录的 PDF，输入序号选；
3. 粘贴完整路径。

## 三、新版式怎么处理（重点）

新 PDF 第一次进来，先跑一次 `启动工具.bat`：

1. 程序先按正文认**阀门类型**（球阀/蝶阀/切断阀/开关阀…），再拿这份 PDF 的
   **字段名**和每份配置对一遍，命中率最高的配置自动采用；
2. 命中不了 → 判为未知版式，只解析前 3 页，生成 `mappings\自动_<文件名>.json`，
   并弹【红线框核对窗口】；
3. 第一次的结果通常只有 50%~80% 正确，这时用 **`批量映射.bat`** 快速补：

### 映射工作台（批量映射）

```
┌──── 左：PDF（红框=已映射 / 青绿=未映射）────┬──── 右：字段名 → 写入列 ────┐
│ ◀ 1/1 ▶  阀门：[阀门1 XV-01 ▾]            │ [模板列 D 口径 ▾] [应用到选中行]│
│                                            │ ☑ 插到该列前面（不覆盖）        │
│   框住"管线压力等级 300#"                   │ 序号 字段名        值     写入列│
│                                            │  6  管线压力等级   300#   D    │
└────────────────────────────────────────────┴───────────────────────────────┘
```

- **多选行**（Ctrl/Shift）→ 上面选模板列 → 【应用到选中行】，一屏定几十项；
- 点表格行 → 左边蓝框高亮对应格子；点左边格子 → 右边选中对应行；
- **☑ 插到该列前面**：默认勾上。意思是"在 D 前插一列"，
  老 D 列内容整体右移、不覆盖；取消勾选则直接写进该列（会顶掉原内容）；
- 【只显示未映射】把已搞定的藏起来；
- 【保存到版式配置】写进 `mappings\*.json`，提示里会给**完整路径**；
- 【保存并生成报价表】保存后直接出 `<PDF名>_报价表.xlsx`；
- 【按字段名自动对齐】用历史记忆 + 语义模型先给一版建议。

### 核对窗口（单格精修）

`完整菜单.bat → 3`，或工作台里点【打开核对窗口】。

左边 PDF、右边字段清单，红框=已进报价表、青绿=没映射。拖一个框就会弹窗，问你：

- **这一格是：字段名 / 主值 / 副值** —— 先框字段名再框值，就能**新建一个键值对**；
- **写入列** + **插到该列前面** —— 和 Excel 里插列一个逻辑；
- 字段名**可以直接手打**（下拉框可编辑），把自动识别的错名字改掉；
- 值框完了发现键不对 → 点 **【键不对，去框正确的键】**，接着框一下正确的键，配对会自动完成；
- **双击右侧任意一行** → 直接改字段名/写入列，或点 **【删除这条映射】**（重复映射就靠它删）。

### 人工修正 / 人工审核

核对窗口工具条上的【人工修正】，列出这个版式所有人工改动，分三类：

| 类型 | 含义 |
|---|---|
| 取值修正 | 第几项改从 PDF 第几列取值 |
| 字段映射 | 字段名 → 报价表哪一列（工作台/核对窗口改的） |
| 新增列 | 插在模板哪一列后面 |

选中 → 【删除选中】即刻生效。删完再跑一次报价表就是新结果。

## 四、版式库（mappings/）

一类 PDF 一个 json，`自动_*.json` 是程序自己学的（可以改、可以删）。

| 文件 | 覆盖的版式 |
|---|---|
| `气动截断阀数据表_21列双侧.json` | 21 列，左栏主规格 + 右栏执行机构/附件 |
| `仪表数据表_开关球阀_12-13列.json` | 仪表数据表 12/13 列单阀版（开关球阀/切断阀） |
| `仪表数据表_蝶阀_23列.json` | 23 列蝶阀，@Max/@Nor/@Min 三列 |
| `仪表规格书_切断阀_12列.json` | 12 列规格书，位号写在表格下方汇总小表 |
| `仪表规格书_开关阀_8-9列.json` | 8/9 列双栏规格书 |
| `备注翻译词典.json` | **不是版式**，是备注翻译词典（见下） |

新来一版式不用手写：跑一次 → 生成 `自动_*.json` → 工作台里改 → 直接就是正式配置。

## 五、取值规则（为什么不怕版式小改）

各家数据表的"第几项""第几列"都不可靠，所以定位按优先级：

1. `fields[].pat`：配置里写的字段名正则（最准）；
2. **字段名相似度**：中文按 2-gram、英文按整词；
3. 写死的 `seq`：只在名字完全对不上时兜底。

值本身按**行内相对位置**找：字段名右边第一个像值的格子，右边界是右栏序号列。
所以改版插一行、多页文件后面多一格、左右两栏各一套序号，都不会取错。

配置里还有几个常用键：

| 键 | 作用 |
|---|---|
| `fields[].src_col` | 精确指定取这一行第几列（可给列表拼接），如 `@Nor` 那一列 |
| `fields[].unit_col` | 单位单独一列时拼到值后面（`deg C`→`℃`、`Mpa-g`→`MPaG`） |
| `transform` | `failure_pos`（FC/FO→关/开）、`pressure_class`（Class 900→CL900）、`min_temp`（`/-45`→`-45`） |
| `extra_columns` | 模板没有的列：`{title, seq, src_col, after:"D"}` = 在 D 后面插列 |
| `placeholder: true` | 只建表头、不写值的占位列 |
| `remark` | 拼备注列，`include_labels` 按字段名取，`triplet` 取 Max/Nor/Min |

## 六、页面备注（备注原文 / 翻译备注）

数据表底部常有备注（表内 `Notes/备注` 行，或表格下方一段），**不同页可能不一样、可能是英文**。
配置里打开 `parse.footnote` 后，报价表在备注列右边多两列：

- **备注原文**：PDF 原文，逐页写到该页那台阀那一行；
- **翻译备注**：英文自动翻中文，本来就是中文的原样保留。

翻译走离线词典 `mappings/备注翻译词典.json`：

```json
{ "templates": [ {"en": "Maximum Stroke Time to Close: {n} seconds",
                  "zh": "最大关闭时间：{n} 秒"} ],
  "phrases":   [ {"en": "Extension Bonnet", "zh": "加长阀盖"} ] }
```

词典里没有的英文会原样留在"翻译备注"里，补进 `phrases` 下次就生效，不用改代码。

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 双击 bat 一闪而过 | 多半是路径带空格/中文导致 Python 没找到；改用 `完整菜单.bat`，或在 cmd 里 `python pdf_table_master.py --menu` 看报错 |
| `ModuleNotFoundError: No module named 'pdfplumber'` | `pip install -r requirements.txt`（确认装到了 bat 找到的那个 Python） |
| 提示"没解析出阀门/没有文字层" | 这份 PDF 是扫描件；本工具不做 OCR，先用别的软件转成文字版 |
| 结果空了一大片 | 跑 `完整菜单.bat → 6 空值体检`：分清"PDF 本来就空"和"漏读" |
| 版式认错、填错列 | `批量映射.bat` 里改：先看左边红框落在哪，再在右边指定写入列 |
| 改了映射没生效 | 保存后会自动清缓存；如果还不对，检查是不是选了"插列"又多出一列 |
| 想推到重来 | 删掉 `mappings\自动_*.json` 和 `_cache\`，再跑一次 |

## 八、给维护者

- **加新版式**：跑一次 → 改 `mappings\自动_xxx.json` → 改名去掉 `auto` 即可当正式配置；
- **删除映射**：核对窗口双击一行 →【删除这条映射】（会同时清 fields / overrides / 同名新增列）；
- **清缓存**：删 `_cache\` 目录（改配置后程序也会自动清）；
- **入口参数**：
  - `python pdf_table_master.py <PDF>` 一键出表
  - `python pdf_table_master.py --menu` 菜单
  - `python pdf_table_master.py --map <PDF>` 映射工作台
  - `python pdf_review.py <PDF> [配置]` 只开核对窗口
